MODULE 01 · NORMAL DISTRIBUTION

Manufacturing Quality Control

Are manufactured components staying within their required dimensions?

⚙
Industry problem

A factory manufactures components whose measured diameters vary around a target. The quality team uses a normal model to estimate the proportion that meet specification and the proportion that may be defective.

MODULE 02 · EXPONENTIAL DISTRIBUTION

Cloud Request Inter-arrival Time

How long might a cloud server wait between incoming requests?

☁
Industry problem

A cloud service receives user requests over time. If requests arrive at a steady average rate, an exponential model can describe the waiting time between consecutive requests (under a Poisson-arrival assumption).

SET YOUR VALUES

Arrival parameters

The rate must be positive. The waiting time must be zero or greater. The mean waiting time is 1/λ.

EXPONENTIAL MODEL
f(t) = λe−λt,   t ≥ 0
F(t) = P(T ≤ t) = 1 − e−λt

MODULE 03 · CENTRAL LIMIT THEOREM

Warehouse Processing Time

How reliably can a warehouse estimate its average order-processing time?

▦
Industry problem

Individual order-processing times vary. By repeatedly taking random samples, a warehouse can study sample averages. The Central Limit Theorem says that, under suitable conditions, the distribution of sample means becomes approximately normal as sample size grows.

SET YOUR VALUES

Population and sample

This calculator uses the normal approximation to the sampling distribution of the mean. A larger sample generally makes the approximation more reliable.

SAMPLING DISTRIBUTION
SE = σ / √n
Z = (X̄ − μ) / SE
SE is the standard error of the sample mean.
